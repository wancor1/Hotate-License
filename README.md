## 主要な特徴

- ファイル単位の弱いコピーレフト。Hotate対象コードを取り込まない独立ファイルの公開は要求しません。
- 対象物を配布する場合、対象部分の対応ソースを無料で入手できるようにします。完全なソースか、正確な元ソースと再現可能な差分を使用できます。
- Hotate対象コードを改変して配布する場合、対象と具体的な変更内容を記録します。
- 商用利用、独自アプリケーションとのリンク、内部利用を認めます。
- 著作者人格権について、法令で認められる範囲で許諾範囲の改変への事前承諾・不行使を明示しています。
- GNU系ライセンスの特定バージョン向けに追加許諾規定を設けています。私的な結合・改変と、GNU系条件に従う配布とを区別します。互換性の正式認定ではありません。
- ライセンス版の移行は Now / New 方式に従います。
- 正式なライセンス全文は、第18.15項により内容を変えずに複製・再配布できます。
- 公式の配布終了宣言は公式配布を `Stopped` にするものであり、過去の許諾や第三者の再配布を取り消しません。

## ソフトウェアへ適用するには

1. 権利を持つ対象ファイルまたは一括指定の対象範囲を明確にします。
2. 正式発行済みの該当バージョンのライセンス全文、または無料の入手先を案内します。
3. `EXAMPLES.md`を参考に個別通知または一括指定を記載します。
4. 第三者コードが含まれる場合は、その権利・通知・許諾条件を別に確認します。
5. 改変物を配布するときは対応ソース、具体的な変更履歴、必要な表示を提供します。

`LicenseRef-Hotate-1.0` は独自のSPDX形式識別子であり、SPDX公式一覧への登録を示すものではありません。
